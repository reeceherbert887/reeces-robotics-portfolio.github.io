# Reece's Robotics Portfolio

This is a Jekyll/GitHub Pages portfolio site.

## Local preview

```bash
bundle exec jekyll serve
```

Then open:

```text
http://127.0.0.1:4000
```

## Notes

- Do not edit `_site/`; it is generated by Jekyll.
- Main pages are in the root folder.
- Project collections are stored in `_course-projects/`, `_society-projects/`, `_summer-projects/`, and `_personal-projects/`.
