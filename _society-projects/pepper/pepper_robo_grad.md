# Pepper Robo Grad

## Overview

Pepper Robo Grad is a graduation-themed presentation project created for the Pepper humanoid robot to celebrate student achievements and support university events.

## Features

* Graduation-themed multimedia presentation
* Automated speech and behaviour sequences
* Video and slideshow integration
* University branding support

## Technologies Used

* Pepper Robot
* Choregraphe
* NAOqi Framework
* Multimedia presentation tools

## Purpose

The project was created to provide an engaging robotic presentation experience for graduation ceremonies, open days, and university showcase events.
