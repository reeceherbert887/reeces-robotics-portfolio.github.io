# Pepper Refreshers

## Overview

Pepper Refreshers is an interactive presentation project designed to support student engagement activities and society events.

## Features

* Multimedia presentation support
* Video playback integration
* Interactive robot behaviours
* Event-focused content delivery

## Technologies Used

* Pepper Robot
* Choregraphe
* NAOqi Framework
* Embedded multimedia content

## Purpose

The project was developed to provide an engaging way of presenting information during refresher events and student activities while showcasing Pepper's interactive capabilities.
