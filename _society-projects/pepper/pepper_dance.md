# Pepper Dance

## Overview

Pepper Dance is an interactive entertainment project developed for the Pepper humanoid robot using Choregraphe and the NAOqi framework.

## Features

* Choreographed dance routine
* Multimedia integration
* Automated behaviour execution
* Audience engagement through robot movement

## Technologies Used

* Pepper Robot
* Choregraphe
* NAOqi Framework

## Purpose

The project was created to explore Pepper's movement capabilities and demonstrate how robots can be used for entertainment and public engagement activities.
